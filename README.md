# Mariam Petrosyan — AI Content Creator Portfolio

Static portfolio website featuring AI product visualization, cinematic AI video/Reels, lighting-focused visual work, and web/content support.

## Local preview
Open `index.html` in a browser, or run a simple static server.

## Deployment
This project is ready for Vercel as a static site. The project root is this folder; no build command is required.

## Update workflow
1. Add/replace assets under `assets/`.
2. Update `index.html` project cards/copy as needed.
3. Test locally on desktop and mobile.
4. Commit changes to GitHub.
5. Vercel will redeploy automatically when Git integration is enabled.
